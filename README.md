# Shared Shopping List
Static page (index.html) + Supabase (database + realtime). Host free on GitHub Pages.

1. Supabase: create a project, run `schema.sql` in the SQL Editor.
2. Copy Project URL + publishable key (Settings > API) into the top of the script in `index.html`.
3. GitHub: create a repo, upload these files, then Settings > Pages > Deploy from branch `main` / root.
4. Send the Pages link to the other person. Each person types their name once.

Note: anyone with the link can edit the list (no login). Keep the link private.
